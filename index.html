code Oracle SQL draft 
SELECT 
    s.student_id,
    s.first_name || ' ' || s.last_name AS student_name,
    d.dept_name,
    e.course_id,
    e.marks
FROM 
    college.students s
JOIN 
    college.departments d ON s.dept_id = d.dept_id
JOIN 
    college.enrollments e ON s.student_id = e.student_id
WHERE 
    UPPER(d.dept_name) = 'COMPUTER SCIENCE'
    AND e.marks > 80
ORDER BY 
    e.marks DESC;

architecture 1. How this query works
2 tables used 1 filter added

This example connects each student to their course enrollment using the shared student ID. It then keeps only the CS101 results so you can review the marks and grades.

Starts with STUDENTS (s) student_id, first_name, last_name, dept_id
Connects with Matching student IDs ON s.student_id = e.student_id
Looks for ENROLLMENTS (e) course_id = 'CS101' → marks, grade

speed 3. Before you run anything
filter_alt Why this filter is here

The example uses UPPER(e.course_id) to guard against case-discrepancies in course catalogs. Recommend establishing a function-based index on ENROLLMENTS(UPPER(course_id)) if the table becomes large. Check the execution plan and your data before adding an index.

account_tree What the database may do

Oracle’s cost-based optimizer may choose a HASH JOIN or NESTED LOOPS or another join method depending on table sizes and statistics. The string concatenation operator || is supported by Oracle.
